# Five-Nights-at-Manolo-s
Five Nights at Manolo's (FNAM) es una colección fan-made inspirada en Five Nights at Freddy's. Incluye los juegos 1, 2, 3, 4, Sister Location y UCN, con Pizzeria Simulator posiblemente en el futuro.  Disponible en Windows, Android, iOS y HTML5. Linux próximamente.  Créditos: Scott Cawthon e irv77 (https://github.com/irv77).
